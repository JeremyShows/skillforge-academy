# Contributing to SkillForge Academy

Contributions are welcome for the course runtime, certification study experience, original learning content, accessibility, testing, and documentation. Begin with the [contributor onboarding guide](docs/contributor-onboarding.md); it explains the supported setup, architecture, validation, and RepoPact process.

For a substantive change, find or register a RepoPact work item before implementation. Keep the change within its acceptance criteria, preserve existing learner data and backup compatibility, and attach command evidence to the work item. Open a focused pull request against `main` and request an independent technical review for architecture, persistence, privacy, content, accessibility, or release changes.

All submitted learning material must be original. Do not contribute recalled live exam questions, exam dumps, reconstructed vendor PBQs, proprietary answer keys, private course material, credentials, or local machine paths. Use public package contracts and sanitized examples for any optional integration.

GitHub approval requirements are not implied by this guidance. The active default-branch ruleset currently blocks deletion and non-fast-forward updates; it does not require a fixed number of approvals or status checks. RepoPact technical review and the repository's separate governance-closeout process remain distinct from GitHub's ruleset. See the onboarding guide for the verified process and commands.
