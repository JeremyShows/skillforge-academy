## Pipeline and governance observations

`.github/workflows/release.yml` runs on `v*` tags or manual dispatch. Its Windows test job runs content, accessibility, Vitest, frontend build, and Rust checks; the tag release job creates a draft, conditionally signs, and uploads SHA-256 checksums. It does not run on ordinary pull requests. The release job currently specifies `prerelease: false`, so a future beta tag needs a reviewed pipeline correction. The active GitHub default-branch ruleset has deletion/non-fast-forward protections but no required reviewer count or status-check rules; RepoPact technical independent review remains a separate quality practice.

## Required next steps for WI331

1. Reconfirm the 2.0.0-beta.1 scope and SemVer decision after WI310, WI311, and WI322 status is reconciled.
2. Resolve or explicitly bound WI325–329 data and feature gaps; specify exactly which state migrates and which recovery/import formats are supported.
3. Keep the existing Tauri identifier unless isolated upgrade testing proves a deliberate identity change safe.
4. Correct and review draft/prerelease semantics in the release workflow before tagging.
5. Build from a clean committed candidate; record full commit, artifact name, file size, checksum, signing state, build environment, and content revision.
6. Pass the required automated checks and obtain independent Windows CI for that exact commit.
7. Test clean installation and upgrades in an isolated environment; verify learner state, backup round-trip/recovery, package compatibility, accessibility limits, privacy redaction, and uninstall/reinstall behavior.
8. Publish accurate notes, known limitations, and checksums; check for private material or credentials in the public artifact.
9. Obtain required governance authorization and explicit maintainer approval before creating a public tag or publishing the release.

Do not use the existing 1.4.1-beta.1 artifact as a v2 release candidate, install over a maintainer's real application, modify real learner data, or publish a tag before these gates pass.
