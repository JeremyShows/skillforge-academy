# Public and Private Course Boundary

The public repository contains the generic SkillForge runtime, public built-in
course packages, public-safe schemas, tests, and architecture documentation.

Private repositories may contain private course packages, source material,
course-specific assets, private evidence, and private learner records. Private
content is never staged, copied, cherry-picked, or temporarily committed to
public history.

Package origin may affect trust and update metadata, but it must not change
learning semantics. Public, local, enterprise, and private packages use the
same validated declarative contract. No package may encode learner identity or
provider secrets.
