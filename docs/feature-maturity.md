# Feature maturity matrix

Status is assessed against source at `origin/main` commit `17be629702ef57ffd38db35c5d541745f02e73b0` (2026-10-09). “Implemented” means the bounded behavior described in that row exists in this repository; it does not imply production qualification or completion of a larger proposal.

| Subsystem | Status | Verified behavior and limits | Evidence |
| --- | --- | --- | --- |
| Platform shell and course runtime | Implemented | PlatformHub selects a validated built-in or locally imported package and creates a shared runtime context. Course material is data, not executable code. | [PlatformHub](../src/platform/PlatformHub.tsx), [runtime](../src/platform/runtime.ts), WI 316–320 |
| Declarative course package and validation | Implemented | Versioned manifest, canonical Course hierarchy, optional catalogs, strict schema/reference checks, capability rejection, and package fixtures exist. | [package validation](../src/platform/packageValidation.ts), [package types](../src/platform/packageTypes.ts), [schema](../schemas/skillforge-course-v1.schema.json) |
| Course registry and package lifecycle | Implemented | Built-ins and user-installed packages are kept separate; local import, validation, version comparison, export, and removal are implemented. There is no remote catalog or download service. | [registry](../src/platform/registry.ts), [distribution boundary](COURSE-DISTRIBUTION.md) |
| Built-in certification study workspace | Implemented | A+, Network+, and Security+ retain the legacy lessons, practice, PBQs, mock exams, recall scheduling, analytics, notes, bookmarks, and backup path. | [certification manifest](../src/content/certifications.json), [legacy logic](../src/logic.ts), [backup code](../src/backup.ts) |
| Built-in certification course projection | Experimental | Each eligible built-in track is projected from domains and lessons into generic modules, instruction activities, and optional remediation. Legacy question/PBQ/flashcard banks are not fully projected; generated course capstone/final assessments are empty and the built-ins do not author lecture, academic, or lab catalogs. | [public package builder](../src/platform/publicPackages.ts), [projection notes](BUILT-IN-COURSE-PROJECTION.md), WI 329 proposed |
| Classroom and lesson progression | Implemented | Course activities and resume location are derived from authoritative CourseProgress. The UI does not grant completion just by displaying a lesson. | [CourseProgress](../src/course/progress.ts), [classroom planner](../src/classroom/planner.ts), WI 320/324 |
| Course assessment, mastery, and remediation engine | Implemented | Authored activity responses, mastery rules, remediation targeting, retry, and module-assessment progression update CourseProgress. | [course progress](../src/course/progress.ts), [course runtime](../src/platform/runtime.ts), `src/platform/modern-runtime.test.ts` |
| Capstone stage and academic evaluation parity | Planned | Stage-specific context, evaluation/evidence commit, and complete Academic Record parity are deferred to proposed WI 325. The built-in projections do not contain authored capstone assessments. | [academic derivation](../src/academic/progress.ts), WI 325 |
| Lecture delivery | Experimental | Authored lecture sequences and runtime exist. Formal activity UI work remains active in WI 322; durable lecture cursor/response state is proposed in WI 326. | [lecture runtime](../src/lecture/runtime.ts), [activity bridge](../src/platform/lectureActivityBridge.ts), WI 322/326 |
| Labs and practical activities | Experimental | Deterministic, data-authored lab state machines exist, but completion reachability and persisted lab runs remain proposed in WI 327. Executable/network-backed labs are rejected. | [lab runtime](../src/labs/runtime.ts), [package security](COURSE-PACKAGE-SECURITY.md), WI 327 |
| Instructor service | Implemented | A bounded deterministic provider-neutral fallback is available and cannot change CourseProgress. There is no external instructor provider integration in the public runtime. | [instructor service](../src/instructor/service.ts), [types](../src/instructor/types.ts) |
| Academic records and evaluations | Experimental | Academic records derive from authored catalog data and CourseProgress; they are not an independent persisted grade book. Stage-specific parity is proposed in WI 325. | [academic progress](../src/academic/progress.ts), WI 324/325 |
| Learner-state persistence and recovery | Implemented | WI 324 adds a canonical envelope owner, hydration-before-mutation, serialized writes, durable acknowledgements, malformed-record quarantine, native bounded/atomic persistence, and shutdown quiescence. Native platform-envelope backup/restore acceptance remains open in WI 328. | [envelope store](../src/platform/persistence.ts), [shutdown coordinator](../src/platform/windowShutdown.ts), [Tauri commands](../src-tauri/src/lib.rs), WI 324/328 |
| Legacy certification compatibility | Implemented | The existing application identity, `apex-state`, and `.apexbackup` imports are retained. Automatic legacy progress migration into the course runtime and feature parity are deferred to WI 329. | [legacy state](../src/state/learnerState.ts), [backup classification](../src/platform/persistence.ts), WI 324/329 |
| Privacy, diagnostics, and existing backups | Implemented | No account, telemetry, or crash upload is required; diagnostics are local/user initiated; existing encrypted backup and import safeguards remain. This does not qualify platform-envelope backup/restore for a new release. | [diagnostics](../src/diagnostics.ts), [privacy review](privacy-security.md), [backup guide](backup-restore.md), decision 0009 |
| Remote course distribution | Deferred | Signed downloads, trusted publishers, remote updates, revocation, and a marketplace/catalog are not implemented. The current lifecycle is local package import/export. | [distribution boundary](COURSE-DISTRIBUTION.md) |
| External/proprietary service integration | Deferred | The public app and package runtime work without an external service. No proprietary provider implementation or private course dependency is part of this public runtime. Use only the public package and provider-neutral contracts. | [instructor fallback](../src/instructor/service.ts), [package security](COURSE-PACKAGE-SECURITY.md) |
| Android development foundation | Experimental | Tauri Android scaffolding and development checks exist; this is not a public release commitment. | [Android status](android-mobile.md), WI 217 |
| iOS delivery | Deferred | iOS remains blocked on macOS/Xcode-hosted runtime and permission validation. | [iOS status](ios-mobile.md), WI 218 |
| Windows desktop distribution | Implemented | Published Windows releases exist; the latest public release is v1.3.2. Current releases are unsigned while the signing certificate remains unavailable. | [GitHub releases](https://github.com/ForgeWireLabs/skillforge-academy/releases), [signing status](CODE-SIGNING.md), WI 212 |
| 1.4.1-beta.1 candidate qualification | Experimental | This candidate is unpublished and packaged-app acceptance remains pending. It does not qualify current main or a future v2 build. | [candidate record](beta-candidate-1.4.1-beta.1.md), WI 310 |
