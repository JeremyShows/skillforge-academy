# Public Package Security Scan

The security tests reject script, command, shell, PowerShell, Bash, process,
native library, dynamic import, arbitrary local path, environment-variable,
provider endpoint, credential, and secret-shaped fields. Unsupported future
capabilities are reported and are not installed or executed.

Package parsing is bounded before JSON parsing where possible, and validation
limits strings, collections, references, lectures, labs, assets, and
migrations.
