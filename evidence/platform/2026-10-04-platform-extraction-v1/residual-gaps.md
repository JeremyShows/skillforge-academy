# Residual Gaps

- Full Course Studio UI is not implemented; the canonical package model and
  Build-mode handoff are documented.
- Marketplace/site distribution is not implemented.
- Package signatures, trusted publishers, remote updates, and revocation are
  future work.
- The legacy certification workspace remains a compatibility view while richer
  public course runtime coverage expands.
- Public Tauri-native package installation is represented by the generic local
  import boundary; desktop resource packaging remains a follow-up when package
  distribution moves into the shell.
