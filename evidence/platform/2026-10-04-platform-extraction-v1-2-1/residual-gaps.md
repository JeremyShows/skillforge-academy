# Residual gaps

- Browser acceptance is limited to the neutral import and learner flows recorded in `browser-acceptance.json`; it is not a release smoke test for every built-in certification.
- The public runtime currently supports the declarative package capability set. Unsupported native, network, and executable capabilities remain explicitly rejected rather than emulated.
- No merge is performed in this closure. The branch is pushed for independent review and comparison against its exact requested base.
